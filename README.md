# aws-end-to-end-devops
Projeto end-to-end de CI/CD implementando Infrastructure as Code com Terraform para provisionamento de recursos na AWS (VPC, subnets, NAT Gateway, EC2 privadas e reverse proxy Nginx).  A aplicação Web é containerizada com Docker, armazenada no Amazon ECR e atualizada automaticamente através de pipeline, integrando infraestrutura e deploy contínuo.
